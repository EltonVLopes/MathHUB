# MathHub

O **MathHub** é um projeto pessoal desenvolvido em C++ com o objetivo de reunir ferramentas para cálculos matemáticos, financeiros e conversões de unidades.

O projeto está em desenvolvimento e será aprimorado gradualmente, com novas funcionalidades e recursos a cada versão.

## 🚀 Versão 1.0 — Calculadora de Descontos

A primeira versão do MathHub apresenta uma calculadora de descontos, permitindo que o usuário informe o preço de um produto e a porcentagem de desconto desejada.

### Funcionalidades

- Informar o valor original do produto.
- Informar a porcentagem de desconto.
- Calcular o valor correspondente ao desconto.
- Calcular o preço final do produto.
- Validar os valores informados pelo usuário.
- Solicitar novamente os valores quando forem inválidos.

### 🛠️ Tecnologias utilizadas

- **Linguagem:** C++
- **IDE:** Code::Blocks

### 🧮 Exemplo de cálculo

Considerando um produto de R$ 100,00 com desconto de 25%:

| Descrição | Valor |
|---|---:|
| Preço original | R$ 100,00 |
| Desconto | 25% |
| Valor descontado | R$ 25,00 |
| Preço final | R$ 75,00 |

### 📚 Objetivo do projeto

O MathHub também tem como objetivo colocar em prática os conhecimentos adquiridos durante os estudos de programação, desenvolvendo habilidades em lógica de programação, estruturas condicionais, laços de repetição e operações matemáticas.
